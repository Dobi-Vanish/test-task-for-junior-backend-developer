# Выполненное тестовое задание

## Быстрый запуск

Склонируйте проект и запустите при помощи Makefile:

`
git clone https://github.com/Dobi-Vanish/test-task-for-junior-backend-developer
`

`
make build
`

`
make up
`

Для завершения:

`
make down
`

После запуска сервис будет доступен по адресу `http://localhost:8080`. Строка подключения к MongoDB: `mongodb://admin:adminpass@localhost:27017/`


## Swagger

Swagger UI:

```text
http://localhost:8080/swagger/
```

OpenAPI JSON:

```text
http://localhost:8080/swagger/openapi.json
```

## API

Базовый префикс API:

```text
/api/v1
```

Автоматическая смена статусов не была добавлена т.к. действия могут занять не то время, что распланировал человек, а также когда человек вручную отмечает статус
то это нагляднее можно увидеть сколько реального времени заняла эта задача.
В процессе разработки хотел добавить уведомления, отправляемые, например, в Telegram,
но в процессе решения понял, что это сильно отходит от первоначальной задачи. Также думал добавить неизменяемые задачи с фиксированным временем,
но это также подразумевало бы создание функционала для личного кабинета - кто-то должен создавать эти задачи, а кто-то должен их отмечать для выполнения,
поэтому от этой идеи тоже отказался.
